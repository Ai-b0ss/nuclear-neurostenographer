# Нейро-стенографист · Nuclear IT Hack 2026

**Android-приложение для локальной расшифровки аудиозаписей с определением говорящих и временными метками.**

**Состояние:** экспериментальный GigaAM v3 ASR и pyannote + ERes2Net диаризация подключены через sherpa-onnx 1.12.20. Android debug APK и instrumentation APK собираются; Windows JNI распознавание и возврат говорящего A–B–A проверены. Android inference ещё не запускался. Известное перекрытие голосов вызывает нативный сбой; изоляция процесса на Android написана, но не исполнена. Проверенные результаты и блокеры: [PROGRESS.md](docs/PROGRESS.md).

## Что реализовано
- Kotlin / Jetpack Compose, запрос разрешения микрофона, запись 16 кГц WAV, импорт аудиофайла.
- Независимое Kotlin-ядро сопоставления слов и спикеров; сохраняет идентификаторы A–B–A, обнаруживает пересечения, не приписывает неоднозначную речь вымышленному человеку.
- Экспорт TXT, JSON, SRT из реального ASR. Интервалы в миллисекундах обозначают модельные реплики/входные фрагменты до 20 секунд; слова на границах могут обрезаться. Неоднозначная речь остаётся без говорящего. JSON сохраняет источник интервалов, длительность и предупреждения.
- Импорт PCM16 WAV проверяется до смены источника и сохраняется в локальную копию. Ошибка нового импорта сохраняет предыдущий результат. Добавлен экспериментальный импорт MP3/AAC/M4A/Ogg/FLAC через системный декодер; исполнение на Android пока NOT_RUN. [Ограничения и тесты](docs/AUDIO_IMPORT.md).
- Облачная сборка APK и ручной запуск Android-эмулятора через вкладку **Actions**.
- Нет разрешения INTERNET в манифесте; аудиозаписи не передаются в облако.

## Как получить APK
Откройте [Actions](https://github.com/Ai-b0ss/nuclear-neurostenographer/actions), выберите успешную сборку **Android debug APK and core tests** и скачайте `neurostenographer-debug-apk` из раздела Artifacts. Установите извлечённый `app-debug.apk` на Android 8.0+.

**Старые APK на main содержат только исходную UI-демонстрацию.** Новая интеграция пока сохранена локально: GitHub-запись заблокирована, новый CI не запускался. Публикация нового APK отключена до проверки runtime без TTS/espeak-ng (GPL); подробности — [RUNTIME_LICENSES.md](docs/RUNTIME_LICENSES.md).

## Метрики и память

`python tools/test_score_transcript.py` проверяет расчёт WER/cpWER/DER на авторских
текстовых тестах. [Формат и условия оценки](docs/BENCHMARKS.md) требуют независимой
разметки. У имеющегося русского WAV её нет: метрики остаются **NOT_SCORED**.
Импорт WAV теперь использует меньше памяти с точным совпадением PCM; измерения
Windows не подтверждают пиковую RAM или скорость Android. Облачный тест сохраняет
JSON и снимки PSS даже при последующем сбое; исполнение Android пока не проверено.

## Следующий рубеж
На ПК выполните `python tools/provision_asr.py --model` (Python 3.11+), перенесите `.local/gigaam-v3.zip` на телефон и выберите «Установить модель ZIP». Нужны около 500 МБ свободного места. Модель проверяется по SHA-256. Затем запишите или импортируйте PCM16 WAV (1–2 канала, 8–48 кГц, 0,1–120 секунд), нажмите «Распознать офлайн». Импорт сжатого аудио ограничен размером около 24 МБ; доступность кодеков зависит от устройства, Android-проверка пока NOT_RUN. Для сборки без модели: `python tools/provision_asr.py`, затем Gradle 8.9 / JDK 17 / SDK 35.

Для экспериментальной диаризации выполните `python tools/provision_diarization.py`, перенесите `.local/diarization.zip` и выберите «Установить модели говорящих ZIP». При недоступности диаризации распознавание продолжается с неизвестными говорящими и предупреждением. Дальше нужны Android inference на эмуляторе и физическом ARM64, исправление нативного overlap-сбоя и тесты WER/DER/cpWER на смартфоне. См. [Issues](https://github.com/Ai-b0ss/nuclear-neurostenographer/issues).

**Очистка:** кнопка «Удалить локальное аудио и результат» удаляет записи и временные аудиокопии приложения. Экспортированные документы удаляются отдельно. Это обычное удаление файлов, без гарантии физического стирания с флеш-памяти. Поставщик выбранного документа может самостоятельно использовать облако.

**Безопасность:** публичный репозиторий; не публиковать чужие разговоры, записи встреч, персональные данные, API-ключи или закрытые модельные веса.
