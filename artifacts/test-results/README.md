# Проверки решения

Краткая таблица с точными версиями и ограничениями: [docs/TEST_RESULTS.md](../../docs/TEST_RESULTS.md).

Исходные отчёты/метрики и журналы: [docs/evidence/](../../docs/evidence/). Они остаются в одном месте, чтобы копии результатов не расходились. Для окончательного комплекта должны быть указаны исходный коммит, SHA-256 APK, устройство, тестовый звук, измеренная длительность и фактический результат. Локальный статус сборки не заменяет распознавание на устройстве.
