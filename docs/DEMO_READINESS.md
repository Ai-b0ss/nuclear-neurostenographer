# Готовность демонстрации: запись → обработка → говорящие → стенограмма → экспорт

Дата аудита: 2026-11-03, код `516000f` (позже менялись только тесты, скрипты и документы). Строгое правило: «проверено» означает автоматический тест с ссылкой; всё остальное — `NOT_RUN`. Ссылки на прогоны и цифры — [PROGRESS.md](PROGRESS.md).

**Вывод:** на эмуляторе сценарий проходит целиком; на физическом телефоне не проверялся ни разу. Называть приложение готовым к показу на телефоне нельзя, пока не выполнена [приёмка](PHONE_ACCEPTANCE.md).

## Сценарий показа (≈5 минут, после приёмки)
1. Авиарежим включён. Приложение уже установлено комплектом, оба значка моделей показывают «Заменить» (модели установлены).
2. «Записать разговор»: два участника, A–B–A, 1–2 минуты; показать таймер и уведомление, свернуть и вернуться.
3. «Остановить запись» → «Распознать офлайн»: показать прогресс.
4. Стенограмма: говорящие и интервалы; показать, что сомнительная реплика помечена, а не выдумана.
5. Экспорт TXT/JSON/SRT; открыть файл.
Запасной вариант на случай сбоя микрофона: импорт заранее подготовленного WAV с русской речью.

## Известные границы, о которых нужно сказать честно
Интервалы относятся к фрагментам до 20 с (реплики до 60 с), а не к словам; говорящий — предположение модели; перекрытия не разделяются; качество на естественной речи не измерено; ARM64 не проверен.
