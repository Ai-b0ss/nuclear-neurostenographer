# Импорт, запись и хранение аудио — актуальное описание

Версия документа: 8 ноября 2026. **Старое ограничение 230 МБ из прежнего документа не относится к текущей продуктовой ветке**. [Архив старой реализации](archive/AUDIO_IMPORT_PREVIOUS_2026-11-07.md).

## Входы и ограничения

- Вход: WAV (PCM) через системный Android OpenDocument или обычный микрофон приложения. Поддержка сжатых MP3/M4A/AAC/Ogg/Opus/FLAC зависит от установленного Android MediaExtractor/MediaCodec и фактического кодека файла; реальные кодеки проверены отдельно.
- Верхняя граница входного объекта `AudioSnapshots.MAX_BYTES` — около 5 ГБ, аудио `PcmFileAudio.MAX_FILE_SECONDS` — 8 часов. Эти величины — проверки допустимости ввода, **не доказательство успешного длительного инференса**.
- WAV валидируется по RIFF; декодированные файлы пишутся потоково в PCM16 16 кГц mono с учётом глобальной временной шкалы. Обычный RIFF имеет физический предел размера PCM; 5 ГБ сжатого ввода не означают 5 ГБ декодированного PCM без ограничений.
- Для файлов более 20 минут используется последовательная обработка блоками до пяти минут: таймкоды остаются глобальными, сквозные ID говорящих не гарантируются. Сохранение каждой миллисекунды исходного сигнала между блоками и отсутствие дублирования важнее выдуманного global speaker ID.
- Для микрофона есть стандартная запись и живой предварительный текст; в продуктовом режиме основная обработка выполняется на телефоне без сети.

## Безопасность и приватность

Перед декодированием оригинал из провайдера копируется в контролируемый каталог приложения, пользовательский оригинал не удаляется. Недопустимые/повреждённые входы завершаются ошибкой, временные файлы очищаются на отказах. Нельзя удалять аудио пользователя по внешнему URI.

В **опубликованном** APK 0.3.17 временная PCM-копия удалялась после успешной обработки. В **локальном кандидате с плеером** декодированный WAV перемещается в `filesDir/transcript-audio/<id>.wav`, чтобы человек мог прослушать оригинал с таймкода реплики. Это не копирует гигабайты повторно, но сохраняет дисковое пространство занятым до удаления стенограммы/очистки аудио. Для прежних стенограмм без локального WAV плеер недоступен.
