## Что не сделано (честно)
- Видео демонстрации.
- Точный прогон в среде жюри. CI-эмулятор настроен на 4096M ОЗУ, x86_64, Pixel 5; сценарий (импорт, распознавание, диаризация, экспорт, удаление) в 0.3.14 зелёный на API 34 и 35. Цифры из CI-артефактов (API 35, 11 с аудио: загрузка+распознавание RTF 0,29; диаризация 57 с аудио за 13,4 с, RTF 0,24) — это один небольшой клип, не оценка на записях жюри; пик памяти приложения отдельно не снимался.
- Локальная LLM из слайда: не реализуется по решению команды (признана ошибкой формулировки).
- Конкурсный JSON проверен валидатором на ПК и юнит-тестами; реальный сохранённый на телефоне файл проверяется отдельно (см. PROGRESS).
