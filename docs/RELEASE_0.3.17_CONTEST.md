# Nuclear Neurostenographer — v0.3.17-contest

Итоговая офлайн-сборка для Android 10+, подготовленная к Nuclear IT Hack 8 ноября 2026 года. APK содержит все модели, не требует интернета.

## Что изменилось
- FDDT-адаптеры Рузанны перенесены на Android; уточнение говорящего для слов A3 в областях перекрытия с реальными масками Nemotron C2.
- Приоритет текста и таймкодов A3: FDDT не удаляет исходные слова, а назначает автора только при однозначном совпадении.
- Вместо кругового индикатора записи — полоса, реагирующая на реальный RMS микрофона в обычном и live-режиме.
- Исправлены подписи live, поведение прогресса FDDT, отмена обработки, работа с длинным импортом.

## Результаты
- 4 дополнительные синтетические записи (273 слова): speaker-aware ошибки 171 → 145 (−15,2%); обычный WER не изменился.
- 6 прежних синтетических записей: 292 → 257 (−12,0%, один регрессирующий случай).
- 3 живых разговора: 103 → 93 по автоматическому псевдоэталону; не человеческая разметка.
- 20 групп тестов ядра, Android lint, реальные кодеки MP3/M4A/OGG/FLAC, 21-минутный WAV с речью после 20-й минуты. Подписанный APK проверен на физическом HONOR DNN-LX9.
