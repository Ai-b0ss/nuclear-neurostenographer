# Нейростенография: актуальная готовность, 4 ноября 2026

Репозиторий `Ai-b0ss/nuclear-neurostenographer` **приватный** (проверено через GitHub API). Подписанный `v0.2.0-contest-rc1` — **prerelease**, не финальный продукт; интеграционный PR #16 остаётся черновиком. Исходный коммит RC1 `931ba2c`, CI Android debug/core PASS. Подписанный APK работает на HONOR 10X Lite (ARM64, Android 10, авиарежим).

| Сценарий | Результат и границы проверки |

**Качество:** короткие синтетические дорожки C2 суммарно дали WER 7,88%, но это всего три записи. В более сложных данных ошибки выше; надёжность на естественных многоголосых совещаниях не доказана. Не считать удачный D–M–D представительными данными. Таймкоды относятся к репликам, не словам. Возможны повторы ASR на границах окон и слова без говорящего.

**Выпуск и лицензии:** приватный prerelease с APK доступен только пользователям, имеющим доступ к репозиторию. ZIP GigaAM/C0 не включены в APK, требуется установить их отдельно; C2 включена. Не удалять сохранённые Apache/MIT/OpenMDW уведомления: приватность репозитория не отменяет условий использования и передачи компонентов. Незакрытый обзор перед более широким распространением описан в [RUNTIME_LICENSES](RUNTIME_LICENSES.md).
