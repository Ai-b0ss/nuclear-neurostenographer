## 2. P1: экспериментально снизить пропуски речи

На идентичных PCM и одинаковом scorer сравнить ограниченные изменения:
1. Пороговые маски C2 и гистерезис на короткой активности, без ложной атрибуции.
2. Обособление VAD как триггера ASR от потока C2 (не отбрасывать PCM, не присваивать говорящего на тишине).
3. Разделение границ на уровне 10ms/80ms без дрейфа и корректная обработка overlap/unknown.
4. Отдельное кратковременное сохранение uncertain/partial speaker вместо необратимого speaker ID.
5. Adaptive preview + batch final, не мешая проверенной финализации.

Каждый эксперимент — отдельный именованный флаг/сценарий и A/B с сохранённым контрольным APK/артефактом; минимум два повтора на HONOR для победителя. Ухудшения по latency и memory считать на телефоне, не подменять Windows.

**Gate P1:** заметное снижение **реального** miss/DER на независимом holdout, улучшение без деградации syn3 3/3, ABA 2/2, syn4 4/4. Ориентир: ≥15% относительного улучшения DER на выборке, отсутствие деградации >2 процентных пунктов на отдельных ключевых сценариях. Это целевой критерий, не подтверждённый результат.

## 4. P3: перекрывающаяся речь

Разнести 3 задачи: detect overlap, attribute both overlapping speakers, recover both lexical streams. Первые две тестировать внутри текущей C2; третью — отдельным offline source separation / target-speaker extraction + A3, только если приватное Android ARM64 измерение покажет достаточное качество и вычислительную стоимость. ## 6. Набор метрик и правила принятия решений

Основные: DER отдельно miss/FA/confusion (с и без overlap; фиксированный collar); cpWER и WER, слово → speaker attribution, recall коротких реплик, количество/стабильность идентификаторов и unknown rate.
