# Сводка к чек-пойнту 07.11.2026

Выпуск: **0.3.10-contest** (versionCode 13). Телефон: HONOR 10X Lite (DNN-LX9, Kirin 710, Android 10, arm64). Везде помечено, где **ПК**, а где **телефон**. «ПК» означает тот же код приложения и те же int8-модели, запущенные на Windows; поведение на телефоне от этого может отличаться только скоростью и памятью, но заявлять его как телефонное нельзя.

## Задача и что сделано

Офлайн-Android: запись или импорт разговора → русский текст → автоматически найденные говорящие → реплики с временем → экспорт TXT/SRT/JSON. Всё работает без сети; модели внутри APK.

| Требование | Статус | Где проверено |
|---|---|---|
| Реальное офлайн-распознавание русского (GigaAM v3 RNN-T, A3) | есть | телефон |
| Автоматическая диаризация, устойчивые A-B-A | есть; в 0.3.7–0.3.9 на коротких диалогах ломалось, исправлено в 0.3.10 | ПК; телефон — см. ниже |
| Реплики с интервалами времени, экспорт TXT/SRT/JSON | есть | телефон (0.3.3, 15 экспортов) |
| Импорт файла и запись с микрофона | есть | телефон |
| Живая расшифровка во время разговора | есть (0.3.8) | телефон (синтетика в темпе речи) |
| Перекрытия речи: «Говорящий 1 + Говорящий 2» | есть (0.3.10) | ПК (юнит-тесты); телефон — см. ниже |

## Телефонный прогон тестов 07.11

Пакеты `.realtime` и `.solhigh` (контестное приложение не трогается), установленный APK сверяется по SHA-256. Сырьё: [evidence/device-suite-20261107](evidence/device-suite-20261107/).

**Прогон 1 (код 0.3.9 + новый тест паритета), 16 PASS / 2 FAIL:**
- PASS: живой режим на 7 записях; живая финализация == импорт файла (`c2OfflineParity`); повреждённая C2 не роняет ASR; восстановление после краша, часовой журнал, отмена/перезапуск, восстановление прерванной записи, захват микрофона; замена C2 с откатом; 3 lifecycle-теста.
- FAIL `fixturePipelineAndExports` (импорт файлов): HONOR заморозил процессы приложения (cgroup freezer, 20+ мин без CPU) — тест упал по таймауту C2. Не ошибка кода, но и не PASS: импорт на этом коде на телефоне **не подтверждён**.
- FAIL `foregroundMicrophoneScreenOff`: тесту нужно, чтобы хост выключил экран во время записи; скрипт этого не делал. Ошибка стенда.
- Живой `aba`: 1 говорящий из 2 — это и есть найденная ошибка прогретого прохода.

**Прогон 2 (0.3.10):** ожидает установки на телефон (каждая установка подтверждается на экране). Добавлены: сторож заморозки, шаг выключения экрана, очистка старых доказательств перед импортом.

## Что не проверено

- Живой режим с **микрофона** в настоящем разговоре (только запись в темпе речи); записи живого режима длиннее минуты; нагрев.
- Натуральный разговор с ручной разметкой (DER/cpWER) — только синтетика и читаемый сценарий.
- Перекрытия: слова при одновременной речи не делятся между говорящими; качество распознавания в перекрытии не измерялось.
- Устройства с страницами 16 КБ (Android 15+): ORT Java не выровнен; решается в C++-ветке.
- Эмуляторный CI красный из-за устаревшего UI-сценария (не приложение).
