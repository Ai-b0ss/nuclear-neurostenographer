# Сводка к чек-пойнту 07.11.2026

Выпуск: **0.3.11-contest** (versionCode 14; код = 0.3.10 + словарь терминов). Телефон: HONOR 10X Lite (DNN-LX9, Kirin 710, Android 10, arm64). Везде помечено, где **ПК**, а где **телефон**. «ПК» означает тот же код приложения и те же int8-модели, запущенные на Windows; поведение на телефоне от этого может отличаться только скоростью и памятью, но заявлять его как телефонное нельзя.

## Задача и что сделано

Офлайн-Android: запись или импорт разговора → русский текст → автоматически найденные говорящие → реплики с временем → экспорт TXT/SRT/JSON. Всё работает без сети; модели внутри APK.

| Требование | Статус | Где проверено |
|---|---|---|
| Реальное офлайн-распознавание русского (GigaAM v3 RNN-T, A3) | есть | телефон |
| Автоматическая диаризация, устойчивые A-B-A | есть; в 0.3.7–0.3.9 на коротких диалогах ломалось, исправлено в 0.3.10 | ПК и телефон (прогон 2) |
| Реплики с интервалами времени, экспорт TXT/SRT/JSON | есть | телефон (0.3.3, 15 экспортов) |
| Импорт файла и запись с микрофона | есть | телефон |
| Живая расшифровка во время разговора | есть (0.3.8) | телефон (синтетика в темпе речи) |
| Перекрытия речи: «Говорящий 1 + Говорящий 2» | есть (0.3.10) | ПК (юнит-тесты); телефон — см. ниже |

## Словарь терминов

- **ПК:** 0 ложных правок на 29 диалогах; A3 на пробных фразах пишет «Твел», «Магаты», «Мефи», «Хокотон» → словарь исправляет.
- **Телефон (07.11, .solhigh):** пробная запись 25 фраз, кнопка «Исправить термины (7)» → применение (ТВЭЛ, МАГАТЭ, Хакатон, КИУМ, диаризации) → «Термины исправлены (7)» → откат возвращает исходный текст. Не исправляется то, чего нет в словаре («ВВЭР-1200» → «V 200»). Проверена работа интерфейса, а не точность на живой речи: запись синтетическая, один голос.

## Что не проверено

- Живой режим с **микрофона** в настоящем разговоре (только запись в темпе речи); записи живого режима длиннее минуты; нагрев.
- Натуральный разговор с ручной разметкой (DER/cpWER) — только синтетика и читаемый сценарий.
- Перекрытия: слова при одновременной речи не делятся между говорящими; качество распознавания в перекрытии не измерялось.
- Устройства с страницами 16 КБ (Android 15+): ORT Java не выровнен; решается в C++-ветке.
- Эмуляторный CI: UI-сценарий переписан под текущий интерфейс — зелёный на API 34/35 ([прогон 42318026836](https://github.com/Ai-b0ss/nuclear-neurostenographer/actions/runs/42318026836)); API 33 — таймаут загрузки эмулятора раннера.
