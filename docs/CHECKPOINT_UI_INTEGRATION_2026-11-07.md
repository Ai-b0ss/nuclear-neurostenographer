## Красная проверка UI

Источник: https://github.com/Ai-b0ss/nuclear-neurostenographer/actions/runs/42408964482/job/128512719518

API 33 не дошёл до запуска приложения: Android Emulator не смог создать userdata. Было свободно 7295,98 МБ, требовалось 7372,80 МБ. После этого стенд ждал запуска несуществующего устройства до таймаута. В том же workflow проверки API 34 и 35 завершились успешно.

В подготовленном патче для offline-asr.yml добавлена очистка неиспользуемых Android-сборкой .NET/Haskell SDK на одноразовом GitHub runner перед созданием эмулятора. Матрица 33/34/35, 4 ГБ RAM и размер пользовательского раздела сохранены. Диски домашнего ПК эта команда не затрагивает.

GitHub отклонил отправку workflow с ошибкой OAuth scope: нет разрешения workflow. Поэтому рабочий workflow оставлен прежним, готовая правка сохранена как docs/evidence/checkpoint-20261107/ci-disk-space.patch. Это предложение исправления, ещё не применённое в CI.
