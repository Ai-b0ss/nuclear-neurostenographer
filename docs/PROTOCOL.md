# Спецификация протокола обработки речи

Структура файла сохранена по [шаблону организаторов](https://github.com/grigorevmp/hacathon_template), но содержание относится к кейсу Hex.Team. Исходный шаблон описывает акустическую передачу данных между устройствами; **это не функция** нейростенографа.

## Цели

Преобразовать аудио записи/микрофона в локальную стенограмму: кто, когда, что сказал, с временными метками в миллисекундах. Экспортировать в обязательный формат конкурса.

## Физический уровень

Микрофон Android или WAV/MP3/M4A с системным декодером; входной PCM16 mono 16 кГц используется для инференса. Обмен через динамик между устройствами не выполняется. Интернет и передача аудио серверу не нужны.

## Формат передачи

Пользовательский файл или запись поступает в локальную обработку. Пример конкурсного выхода:

`{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}`

Корень — объект `transcript` с массивом реплик; `speaker_id` строка, включая `"unknown"` для ненадёжной атрибуции; `start_ms` и `end_ms` — целые миллисекунды относительно начала исходной записи, `text` — распознанная речь. Совместимость литерала `unknown` с закрытым парсером не проверена. Расширенные данные отдельно.

## Установление и завершение передачи

В этом кейсе сетевой сессии нет. Начало — выбор аудиофайла через Android OpenDocument или запуск микрофона. Завершение — отображение и сохранение стенограммы; пользователь явно инициирует экспорт. Отмена сохраняет возможность повторной обработки, не подменяет текст готовыми ответами.

## Синхронизация

Временные метки A3 и активности C2 сопоставляются по общей шкале файла. Для длинных файлов offsets блоков сохраняют глобальные миллисекунды. Межблочные ID голосов не выводятся из совпадения локального номера.

## Ошибки и восстановление

При повреждённом аудио, нехватке RAM и сбоях чтения приложение показывает ошибку. При отказе FDDT сохраняется базовый текст A3+C2. Ненадёжная атрибуция не заменяется выдуманным говорящим. Удаление и повторный импорт управляются самим пользователем.

## Совместимость

Основной конкурсный путь: Android ARM64, офлайн GigaAM A3 e2e RNN-T + Nemotron C2 + условный FDDT. Строгая структура конкурсного JSON проверена на HONOR. Подробнее: [ARCHITECTURE](ARCHITECTURE.md), [MODELS](MODELS.md), [TEST_RESULTS](TEST_RESULTS.md).

## Пример

Запись с тремя последовательными говорящими: [WAV](../artifacts/demo/ITAM-demo-3-speakers-33s.wav), [экспортированный JSON](../artifacts/demo/ITAM-demo-3-speakers-33s-export.json) и [видеодемонстрация](../artifacts/demo/ITAM-demo-3speakers-playback.mp4). Видео и плеер принадлежат локальному кандидату, а не опубликованной сборке 0.3.17.
