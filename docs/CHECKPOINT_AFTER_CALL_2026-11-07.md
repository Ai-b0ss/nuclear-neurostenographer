## Реализовано

- Конкурсный экспорт сохраняет `unknown` для неустановленного автора слов. Активность двух голосов сама по себе не назначает весь текст первому из них. Значение `unknown` сохраняет требуемый тип string; совместимость именно этого значения с закрытым парсером жюри не подтверждена.
- При `-PenglishAuto=true` Whisper Tiny INT8 определяет язык по звуку. Английская запись распознаётся локально Whisper, русская остаётся на A3. Никакого перевода речи на другой язык, сетевого API или выбора языка пользователем. Это путь импорта/обычной записи; живая предварительная расшифровка остаётся русской.
- Английские веса закреплены тремя SHA-256, устанавливаются из встроенного ZIP. Лицензия MIT включена. Модели определения языка и распознавания освобождаются последовательно.
- Проверка WAV больше не выделяет FloatArray всей записи. Дисковый reader читает только ограниченный диапазон, с теми же глобальными позициями ресэмплинга.
- Для файлов длиннее 20 минут реализован последовательный путь блоками до пяти минут с исходными глобальными таймкодами. В этом пути **сквозная диаризация пока отсутствует**: текст сохраняется с неизвестными говорящими, что явно отмечается в предупреждениях. Нельзя выдавать это за полную стенограмму с устойчивыми участниками на 8 часах.
- Ограничения импорта расширены до 5 ГБ входного файла/8 часов звука; поддержка многочасового реального разговора этим изменением ещё не доказана. Для декодированного PCM остаётся форматный предел обычного RIFF WAV около 4 ГБ; это особенно существенно для 48 кГц стерео.
- Цифровая тишина не отправляется в генеративный английский декодер. Тихую ненулевую речь порогом громкости не удаляем.

## Сборка

```text
python tools/provision_english.py
gradle --offline :core:runCoreTests :app:assembleDebug :app:assembleDebugAndroidTest -PnemotronProduct=true -PasrA3=true -PenglishAuto=true -PcheckpointQa=true
```

Для использования уже загруженного upstream-архива: `python tools/provision_english.py --model-dir .local/english/sherpa-onnx-whisper-tiny`.
Остальные модели/runtime готовятся штатными средствами проекта. `checkpointQa` создаёт отдельный пакет `.checkpoint`, чтобы тесты не заменяли конкурсное приложение.
