# Офлайн-комплект установки (APK + модели)

Комплект — это папка из трёх файлов с проверкой SHA-256: `app-debug.apk`, `gigaam-v3.zip` (≈225 МБ), `diarization.zip` (≈46 МБ). После установки приложению интернет не нужен: в манифесте нет разрешения INTERNET, а модели лежат в приватной папке приложения.

**Статус:** комплект и скрипты проверены тестами и в CI на эмуляторе. Установка на физический ARM64-телефон — `NOT_RUN` ([PHONE_ACCEPTANCE.md](PHONE_ACCEPTANCE.md)). APK и веса **не публикуются**: лицензионная проверка распространения не завершена ([RUNTIME_LICENSES.md](RUNTIME_LICENSES.md)); комплект предназначен для команды. Runtime — только закреплённый no-TTS (SHA-256 `771fda6a…c1c8`), исходный GPL/TTS-вариант не используется.

## Что нужно на ПК
Python 3.11+, `gh` (авторизован), platform-tools с `adb` (скачивается с developer.android.com, ≈10 МБ), около 1 ГБ свободного места под комплект.

## 1. Получить APK (одно действие владельца)
CI не публикует APK. Для командного использования есть сборка по запросу, которую может запустить только владелец (нужна фраза подтверждения); артефакт живёт 1 день и удаляется сразу после скачивания скриптом:

```bash
gh workflow run build-apk-kit.yml --repo Ai-b0ss/nuclear-neurostenographer --ref feature/long-recordings -f confirm=PRIVATE-USE-ONE-DAY
```

Дождитесь зелёного прогона (≈5 минут), затем:

```bash
python tools/offline_kit.py fetch-apk
```

Скрипт скачивает APK, сверяет его SHA-256 с записанным в CI и удаляет артефакт. Пока артефакт существовал, он был виден всем, у кого есть ссылка на прогон (репозиторий публичный).

Альтернатива без CI: собрать самому (Gradle 8.9, JDK 17, Android SDK 35: `python tools/provision_asr.py`, затем `gradle :app:assembleDebug`). Это требует установки SDK и принятия его лицензии, поэтому я на вашем ПК этого не делал.

## 2. Собрать комплект
```bash
python tools/offline_kit.py assemble --apk .local/apk/app-debug.apk
```
Скрипт скачает модели по закреплённым ревизиям (если их ещё нет), проверит каждый файл, создаст `.local/kit/` с `SHA256SUMS.txt`, `KIT_MANIFEST.json` и `phone_kit.py`. Повторная проверка: `python tools/offline_kit.py verify .local/kit`.

## 3. Установить на телефон (по USB, без выбора ZIP в интерфейсе)
На телефоне: «Для разработчиков» → «Отладка по USB». Затем в папке комплекта:

```bash
python phone_kit.py check
python phone_kit.py install
```
`check` проверяет архитектуру (нужна arm64-v8a), версию Android (≥ 8), свободное место (≥ 1,5 ГБ) и ОЗУ, и напоминает включить авиарежим. `install` сверяет SHA-256 файлов комплекта, ставит APK, кладёт оба ZIP в папку приложения `Android/data/ru.neurostenographer.app/files/kit/`, а приложение при запуске само проверяет файлы внутри ZIP по закреплённым хэшам, устанавливает обе модели и удаляет ZIP. Результат отображается на экране приложения («Комплект установлен…»).

Без `adb` модели можно, как раньше, поставить кнопками «Установить модель ZIP» и «Установить модели говорящих ZIP».

## Ошибки установки
| Что видно | Причина и действие |
| --- | --- |
| `Kit rejected: … checksum mismatch` | файл повреждён при копировании; пересоберите комплект |
| «Мало места для … нужно около N МБ» | освободите место; ZIP остаётся в папке и устанавливается при следующем запуске |
| «gigaam-v3.zip: … Файл оставлен в папке комплекта» | ZIP не прошёл проверку; прежняя модель не затронута; скопируйте комплект заново |
| `NOT_RUN: adb not found` / `expected exactly one authorized device` | нет adb или телефон не подтвердил отладку |

## Размеры и память
APK ≈ 51 МБ (arm64-v8a и x86_64; по данным apk-inspection.json CI). Во время установки нужно место под ZIP, промежуточную копию и (при замене) прежнюю модель; приложение проверяет запас заранее. На эмуляторе пиковая память: приложение ≈ 612 МиБ (загрузка модели ASR), процесс диаризации ≈ 455 МиБ (в разные моменты); на телефоне не измерялось (`phone_kit.py monitor`).
