# Neurostenographer 0.4.0 — post-hackathon engineering release

Дата: 10.11.2026. Основа: `finish/fddt-contest-20261108`, коммит `8ebacb6` (0.3.17-contest).
Рабочая ветка: `release/posthack-v0.4.0`. Конкурсный APK не изменён.

## Изменения

- **Развязка ASR и диаризации.** Для русского офлайн-распознавания объединяются интервалы Nemotron C2 и независимого Silero VAD. Если C2 пропустил речь, обнаруженную Silero, GigaAM всё равно получит её на вход. Используется уже закреплённый Silero, без скачивания новых моделей; при сбое независимого VAD сохраняется предыдущий путь с предупреждением. Чисто цифровая тишина не распознаётся.
- **Длинные записи.** Для аудио длиннее 20 минут сохраняются распознанные локальные метки, таймкоды и перекрытия внутри каждого независимого блока. ID получают префикс `Block N / Speaker M`, поэтому одинаковые локальные номера в разных блоках не объединяются в одного человека. Значение `null` остаётся неизвестным; глобальная идентификация пока отсутствует. В TXT-сводке локальные метки не выдаются за число уникальных людей. FDDT-постобработка внутри блока более не выбрасывается при смещении таймкодов.
- **Live-финализация.** Полный проход Nemotron C2 после остановки записи получает приоритет над предварительным FAST-проходом там, где он определил говорящего. Предварительный проход остаётся резервным для незаполненных участков; перед сопоставлением применяется `SpeakerIdentity.align`.
- **Английский путь.** Независимая сегментация речи используется при определении языка и в Whisper, если английская модель включена.
- **Номер сборки:** `versionName=0.4.0`, `versionCode=21`. Имя пакета прежнее — `ru.neurostenographer.app`; подпись соответствует 0.3.17.

## Известные ограничения и необходимые испытания

1. Физический HONOR в текущем сеансе не подключён. Установка/обновление, фоновые сценарии, запись с микрофона и WER/DER/cpWER новых алгоритмов **не проверены на устройстве**.
2. Независимый VAD снижает зависимость ASR от C2, но не гарантирует восстановление речи, которую пропустили обе модели. Новая сегментация может изменить WER; требуется парный тест на одинаковом естественном русском аудио.
3. Локальные ID по блокам не означают сквозное сопоставление голосов. Настоящая глобальная идентификация между блоками пока не реализована.
4. Приоритет финального C2 обоснован большим контекстом, но его точность против preview-first требует парного сравнения на живой записи.
5. FDDT сохраняет слова A3, а атрибуция перекрывающихся слов может оставаться `unknown`. Полное восстановление отсутствующих слов отключено.
6. Moodle Bridge 2.2.0 работает независимо от этой Android-сборки и не обновляется установкой APK. Для него подготовлен отдельный локальный прототип пословной привязки, но он не внедрён в production.
