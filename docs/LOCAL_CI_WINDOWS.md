# Локальный CI на домашнем Windows-ПК

Установлен на WIN-2LK6007IEBP в K:\nn-local-ci-20261107.
Это отдельный локальный проверяющий процесс, а не зарегистрированный GitHub Actions Runner.
Он ставит статус local/windows-ci на точный проверенный коммит через GitHub API.
Облачные workflow и их статусы не изменяет. Проблема биллинга GitHub остаётся отдельной.

## Что запускается

- 13 Python-проверок из .github/workflows/android.yml; при наличии — тесты контроллера CI.
- Проверка сохранённых свидетельств round11, затем тесты ядра, lintDebug, debug APK и instrumentation APK.
- Проверки TXT/SRT/JSON и конкурсного JSON.
- Проверка разрешений APK, ARM64/x86_64, ELF 16 КБ, отсутствия случайно встроенного звука/моделей и совпадения JNI с закреплённым AAR.

SDK 35, JDK 17, Gradle 8.9 и проверенный runtime используются из локального кеша.
Установка SDK и скачивание AAR не повторяются: SHA-256 проверяется относительно каждого коммита.
Сборка выполняется offline, с двумя Gradle workers и низким приоритетом Gradle.
Эмулятор, физический телефон и фактическое распознавание речи этим прогоном не проверяются.
Android instrumentation APK только собирается.

## Автоматический запуск

Контроллер раз в 60 секунд проверяет main, feature/ui-polish и fix/checkpoint-20261107.
Задания выполняются последовательно, одинаковый SHA повторно не строится.
Исходники переключаются в отдельном worktree K:\nn-local-ci-20261107\workspace.
Рабочие папки Клода и владельца не очищаются. Автоматический git clean не используется.
После проверки контролируются HEAD и отсутствие изменений отслеживаемых исходников.

Токен не записан в конфиг: используется существующая авторизация gh текущего пользователя.
Источник — tools/local_ci_windows.py; установленная копия — controller.py в каталоге CI.
Изменение контроллера в Git само по себе не заменяет запущенную копию: обновление выполняется отдельно после его тестов.
Процесс работает только для этого репозитория и явного списка веток, без форков и произвольных команд из PR.

Ярлык Neurostenographer local CI.lnk в автозагрузке текущего пользователя запускает local_ci_launcher.pyw через pythonw.
Окно терминала не открывается. После входа в Windows контроллер запускается снова, если его не отключили командой stop.
При выключенном ПК проверок нет.

## Состояние, журналы и управление

Текущее состояние: K:\nn-local-ci-20261107\current.json.
Отчёты: K:\nn-local-ci-20261107\reports\<полный SHA>\summary.json и журналы отдельных шагов.
Ошибки фонового запуска: daemon.log. APK в workspace соответствует последнему выполненному заданию;
APK для каждого исторического SHA отдельно не копируется.

```powershell
python K:\nn-local-ci-20261107\controller.py --config K:\nn-local-ci-20261107\config.json status
python K:\nn-local-ci-20261107\controller.py --config K:\nn-local-ci-20261107\config.json stop
```

stop отключает последующую автозагрузку и отменяет только текущий дочерний процесс контроллера.
Для возобновления:

```powershell
pythonw K:\nn-local-ci-20261107\controller.py --config K:\nn-local-ci-20261107\config.json watch --resume
```

Для принудительного повторения сначала остановить watcher и дождаться stopped, затем:

```powershell
python K:\nn-local-ci-20261107\controller.py --config K:\nn-local-ci-20261107\config.json run --ref fix/checkpoint-20261107 --force
```

При повторной установке создать отдельный worktree, ownership.json с repository=Ai-b0ss/nuclear-neurostenographer,
скопировать контроллер/launcher и адаптировать tools/local_ci_windows.example.json. Конфиг и журналы хоста в Git не добавлять.
