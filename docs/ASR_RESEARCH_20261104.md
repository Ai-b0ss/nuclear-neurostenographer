# ASR-20261104-v2: GigaAM A0–A4 и MOSS — результаты (04.11.2026)

Исследовательская ветка `research/asr-giga-moss-20261104`. Не меняет `main`, PR #16 и RC1. Все измерения — **ПК** (Xeon E5-2690 v4, sherpa-onnx 2.0.1, 4 потока); RTF/RAM нельзя переносить на ARM64.

## Данные (и что в них не так)
- **Podlodka** (`bond005/podlodka_speech` @4a91614, ручная расшифровка подкаста, лицензия не указана → только оценка, не распространять). Опубликованные `validation` и `test` **побайтно идентичны** (20/20 WAV и ref), поэтому validation отброшен. **HOLDOUT** = test (20 клипов, 487 с, эпизоды 132/275/292/306). **DEV** = train из других эпизодов (30 клипов, 720 с). Манифест: `evidence/asr-20261104/corpus-manifest.json` (SHA-256 WAV и ref).
- Это монолог/интервью-сегменты без разметки говорящих: WER/CER есть, **cpWER/DER для A0–A4 не считались**. Загрязнение обучающими данными GigaAM неизвестно. ~1,8 тыс. слов на группу — мало.
- Многоголосая часть (MOSS vs A0+C2): 33 дорожки из исследования C2 (26 independent holdout + 3 phone + 4 realmix). Это **синтетическая TTS** (ivkond) и склейки реальных звонков с **автоматической** (VAD) разметкой — не независимая ручная.

## Решения
| Кандидат | Решение | Обоснование |
|---|---|---|
| A0 | baseline | — |
| A1 v3 RNNT | NEEDS MORE EVIDENCE | номинально лучше (−0,4/−0,9 пп), не значимо; без пунктуации; RNNT в Android не проверен |
| A2 e2e CTC | NEEDS MORE EVIDENCE | пунктуация есть; WER то лучше, то хуже; дословные «э-э» |
| **A3 e2e RNNT** | **GO к следующему этапу (ARM64 + 20-мин тест + экспорт цифр)** | WER на уровне A0 при пунктуации (P≈0,86–0,90, R≈0,77–0,81); НЕ замена RC1 без решения владельца |
| A4 multi 220M | NO-GO | достоверно хуже на DEV, 1 ГБ RAM, RTF ×1,3, без пунктуации |
| J1 MOSS | NO-GO для Android сейчас | DER и A-B-A хуже C2, RTF>1 на CPU, 5 ГБ RAM; пересмотр только после GPU-прогона и независимой ручной разметки |
| J2 | NOT_RUN | — |

## Не закрыто
Независимые естественные диалоги с ручной разметкой (cpWER/DER для A-серии); ARM64 (RAM/RTF/ONNX-совместимость RNNT); 20-минутная устойчивость; реальная музыка/шум; ручная проверка стыковых повторов; регистр и пунктуация A3 на диалогах; воспроизведение экспорта e2e из ai-sage.

Воспроизведение: `tools/asr_20261104/` (`prep_podlodka.py` → `fetch_models.py` → `run_asr.py` → `score_asr.py` → `paired_bootstrap.py`; `run_stress.py`; `run_moss_batch.sh` → `score_moss.py`). Гипотезы текстов Podlodka в репозиторий не включены.
