# Исходный код — платформа Android

Программа реализована для Android (ARM64) и полностью работает офлайн. Раскладка каталога следует обязательной идее шаблона — исходники отдельной платформы, — но реальное Gradle-дерево проекта **не переносится**, чтобы сохранить работоспособность.

- [Android и инструкция сборки](mobile/README.md)
- [app](../app/) — Activity, запись/импорт, распознавание, история, UI, экспорт, Android-specific ONNX
- [core](../core/) — алгоритмы формирования стенограммы, таймкоды, выделение говорящих, ETA, тесты
- [build.gradle.kts](../build.gradle.kts) и [settings.gradle.kts](../settings.gradle.kts) — конфигурация проекта

Для запуска нужны Android SDK/Gradle и проверенный комплект весов; никаких облачных API-ключей для распознавания не требуется. Видеодемонстрация и испытания — [artifacts](../artifacts/demo/README.md) и [результаты](../docs/TEST_RESULTS.md).
